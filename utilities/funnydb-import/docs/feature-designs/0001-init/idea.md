- 读取，预处理，发送到 funnydb，支持动态调整串流速率，断点续传
- 使用 github.com/funny/ingest-client-go-sdk/v2 负责处理，检查 cmd/ingest-import 的用法
- 程序要求输入一组数据的 URL，对于每一个 URL
    - 创建一个进度记录文件与之同名，内容是一个 json，记录文件的名称，处理到的位置，以及一个标记位记录文件是否处理完
    - 检查进度记录文件，若未完成，则开始下载文件
    - 下载完成后发送到 funnydb，分批发送，没发送一批更新一次进度
    - 发送完成后，标记文件处理完，删除数据文件
    - 继续处理下一个

- 程序输入参数
    1. URL 列表，一个文件，记录着 URL 列表
        - 输入的数据文件的格式为 jsonl，每行一个 json 对象
    2. 配置文件，设置发送速率，每批发送大小

- 数据处理
  - 每条输入的数据需要做等价的操作：`jq '. += {"#sdk_type": "go-sdk", "#zone_offset": 8} | {"type": "Event", "data": .}'`

- 日志
  - 每隔 15秒打印一次进度
